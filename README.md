# 潮聲以外 · Beyond the Tide

一個 AI 互動敘事實驗。玩家大部分時間在讀小說,少數時刻真正握到方向盤。

> 玩家可以離開 Story Graph;但世界不能因此離開自己。

---

## 這是什麼

一個五十歲的人收到一張三十三年前海邊旅館的 203 房卡,逐漸發現不同年齡的自己曾反覆回到 1993 年,試圖改變生命中無法接受的失去。

核心問題:**如果人生中的失去可以改變,我們應該改到什麼時候才停?**

專案分兩條線:

- **A1** — 原始小說。不預先設計,寫到重大抉擇點就停,當作反推系統的實驗樣本。約八萬字,未完成。
- **A2** — 結構化版本。把 A1 驗證過的角色、情緒、場景轉成可控、可測試、可迭代的敘事系統,再讓 AI 在限定範圍內演出。

A1 是 Generative Narrative Discovery,A2 是 Structured World + Generative Performance。

## 閱讀器

`index.html`,單一 HTML 檔,無相依套件。直接用瀏覽器開啟即可。最早的原型保留在 `v1.html`。

- 正文:N01–N07 作者審稿版 v0.1,7 章 / 43 段場景 / 1,033 句,一字未改(長段落只依句號切開)
- 18 種手繪 SVG 動態場景:辦公室的信、一瞬的畫面、高鐵車窗、平交道與碧海行館、大廳、二樓走廊、203 門前、門縫、203 房、錄音機特寫、夜市、傍晚的街、阿月冰果室、便利商店、港邊、一樓舊餐廳、雨、合照
- 版面是一本插圖書:直式螢幕上圖下文,橫式螢幕左圖右文
- 正文預設直排(由右往左),排滿自動翻頁;目錄裡可改橫排與字級;小螢幕放不下的長句會自動縮小字級
- 場景分前後景,鏡頭會跟著游標/手指微微移動;空氣裡的塵、蛾、燈暈、雨另外畫在 canvas 上
- 畫面上有光點的地方可以碰,碰了會引用原文裡描寫那樣東西的句子;走廊與房間的窗可以開關
- **機關**:讀到「你做了某件事」的句子之前,故事會停下來等讀者親手做,共 22 處——拆開信封、攤開小紙、翻房卡、推開玻璃門、把房卡舉向感應區、放錄音帶、按播放/停止/倒帶、刷卡結帳、轉開瓶蓋、收起錄音機、翻照片、回小澄訊息
- 機關出現後 3 秒內螢幕沒有任何動作,就自動做完往下走;直接點文字頁也一樣(秒數是 `IDLE_MS`)
- 機關清單 `MECH` 與場景狀態 `EVENTS` 用「那一句裡的幾個字」定位,不是用句子編號,所以正文改了也不會錯位;找不到的會在主控台警告
- 場景狀態由閱讀進度推算:房卡在不在信封裡、平交道的柵欄、門開了沒、機器裡是哪一捲、帶子有沒有在轉、隔天的紙箱,跳章節或重新整理都會是對的
- 環境音以 Web Audio 即時合成(海浪、高鐵、日光燈、冰箱、磁帶嘶聲、夜市、雨、電子提示音),沒有音檔
- 進度是一捲帶子,左邊愈讀愈少、右邊愈繞愈多;點它或「目錄」開目錄與設定
- 自動記住進度(存在瀏覽器裡);另有「回顧」與「自動」播放
- 「朗讀」:`audio/` 裡有旁白音檔的段落播音檔,句子跟著旁白一句一句出現;沒有音檔的段落用裝置內建的中文語音(可在目錄裡選聲音)
- 旁白音檔的做法:開 `narration.html`,照上面的分段與檔名產生 mp3,放進 `audio/` 即可。每段不超過 380 字(`CLIP_MAX`),每一句的時間點是閱讀器載入時從波形自動算的,不用另外標
- 鍵盤:空白鍵/方向鍵讀下一句,A 自動,M 目錄,Esc 關閉

**已知限制**:收錄到 N07〈房間不能一直留著〉;進度只存在同一台裝置的同一個瀏覽器;目前沒有旁白音檔(舊稿的 4 段已移除)。

正文存放在 `index.html` 第 391 行的 `const SCENES` — 一整條壓縮過的 JSON。要改文字只需替換這一行,不必動任何 HTML。資料格式:

```js
{ "t": 章節名, "bd": 場景圖, "p": 第幾段, "pt": 共幾段, "l": [句子...] }
```

改檔時記得把 `const VERSION` 往上加,版本號顯示在目錄最下面。

## 編號說明

- **A1 / A2** — 版本。A1 是原始小說,A2 是結構化系統。
- **N01–N30** — Story Node,戲劇功能單位。不等於場景,一個 node 可含多段場景。
- **I1–I7** — Intervention,全劇僅有的七個玩家決策點。
  I1 黃狗(N08) · I2 陳國安/林雨晴(N11) · I3 2016 夏禾(N18) · I4 兒子(N22) ·
  I5 三把鑰匙(N23) · I6 Emergent Restitch(浮現觸發) · I7 最終承諾(N30)

I1–I4 為結構化選項。I5–I7 才開放自由輸入。

## 設計原則

- 用小說讓玩家進入世界,用戲劇讓人物活著,用遊戲讓行動留下後果,用 AI 讓世界真正聽得懂玩家
- AI 可以即興演戲,不可以即興改 Canon
- 玩家擁有自己的意圖、言語與可執行行動;不擁有 NPC、世界狀態、因果結果
- 不介入不是免費的成熟;介入也必須真的創造價值
- 沒有 True Ending
