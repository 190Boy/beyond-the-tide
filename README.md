# 潮聲以外 · Beyond the Tide

一個 AI 互動敘事實驗。玩家大部分時間在讀小說,少數時刻真正握到方向盤。

> 玩家可以離開 Story Graph;但世界不能因此離開自己。

---

## 這是什麼

一個五十歲的人收到一張三十三年前海邊旅館的 203 房卡,逐漸發現不同年齡的自己曾反覆回到 1993 年,試圖改變生命中無法接受的失去。

核心問題:**如果人生中的失去可以改變,我們應該改到什麼時候才停?**

專案分兩條線:

- **A1** — 原始小說。不預先設計,寫到重大抉擇點就停,當作反推系統的實驗樣本。約八萬字,未完成。
- **A2** — 結構化版本。把 A1 驗證過的角色、情緒、場景轉成可控、可測試、可迭代的敘事系統,再讓 AI 在限定範圍內演出。

A1 是 Generative Narrative Discovery,A2 是 Structured World + Generative Performance。

## 閱讀器

`index.html`,單一 HTML 檔,無相依套件。直接用瀏覽器開啟即可。舊版(v1)保留在 `v1.html`。

- 713 句 / 73 個場景 / 11 個手繪 SVG 動態場景
- 版面是一本插圖書:直式螢幕上圖下文,橫式螢幕左圖右文
- 正文預設直排(由右往左),排滿自動翻頁;目錄裡可改橫排與字級
- 場景分前後景,鏡頭會跟著游標/手指微微移動;空氣裡的塵、蛾、燈暈另外畫在 canvas 上
- 畫面上有光點的地方可以碰;走廊與房間的窗可以開關,畫面和海的聲音會跟著變
- 三卷錄音帶要親手拖進錄音機(也可以略過)
- 環境音以 Web Audio 即時合成(海浪、日光燈、磁帶嘶聲、夜市),沒有音檔
- 進度是一捲帶子,左邊愈讀愈少、右邊愈繞愈多;點它開目錄
- 自動記住進度(存在瀏覽器裡);另有「回顧」與「自動」播放
- 「朗讀」會用裝置內建的中文語音念出每一句(沒有音檔,音質依裝置而定);搭配「自動」會念完一句再往下
- 每個場景裡碰得到的東西都有自己的反應(鑰匙晃、門把轉、招牌閃、人影消失…),不新增任何文字
- 鍵盤:空白鍵/方向鍵讀下一句,A 自動,M 目錄,Esc 關閉

**已知限制**:收錄至第三卷結束;進度只存在同一台裝置的同一個瀏覽器。

正文存放在 `index.html` 第 340 行的 `const SCENES` — 一整條壓縮過的 JSON。要改文字只需替換這一行,不必動任何 HTML。資料格式:

```js
{ "t": 章節名, "bd": 場景圖, "p": 第幾段, "pt": 共幾段, "l": [句子...] }
```

改檔時記得把 `const VERSION` 往上加,版本號顯示在目錄最下面。

## 編號說明

- **A1 / A2** — 版本。A1 是原始小說,A2 是結構化系統。
- **N01–N30** — Story Node,戲劇功能單位。不等於場景,一個 node 可含多段場景。
- **I1–I7** — Intervention,全劇僅有的七個玩家決策點。
  I1 黃狗(N08) · I2 陳國安/林雨晴(N11) · I3 2016 夏禾(N18) · I4 兒子(N22) ·
  I5 三把鑰匙(N23) · I6 Emergent Restitch(浮現觸發) · I7 最終承諾(N30)

I1–I4 為結構化選項。I5–I7 才開放自由輸入。

## 設計原則

- 用小說讓玩家進入世界,用戲劇讓人物活著,用遊戲讓行動留下後果,用 AI 讓世界真正聽得懂玩家
- AI 可以即興演戲,不可以即興改 Canon
- 玩家擁有自己的意圖、言語與可執行行動;不擁有 NPC、世界狀態、因果結果
- 不介入不是免費的成熟;介入也必須真的創造價值
- 沒有 True Ending
